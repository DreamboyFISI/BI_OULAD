# Reporte DM1 – Rendimiento académico

Proyecto de Power BI (formato PBIP) del DataMart 1. Se conecta a Azure SQL en modo importar.

Páginas:
- Resultados académicos
- Perfil del estudiante
- Participación y bajas

Para ver los datos: abrir `DM1_Rendimiento.pbip`, ingresar las credenciales de Azure SQL y dar clic en Actualizar.
